Herdr agents

Drive Herdr as a member kind=herdr without owning the TUI. This is not Hermes, OMB, or Rakazo. Default is the Herdr already on this host (no --remote; local server + unix sockets, typically ~/.config/herdr/). Optional remote is a herdr --remote target such as matthewh@10.0.0.36, workbox, or ssh://you@server:2222. If an agent is blocked, submit is rejected. If it is already working, --wait may finish the in-flight turn, not a new one.

Herdr remote (Settings Remotes kind)

Add kind herdr. This is not an HTTP remote like OpenMousBot / Hermes / Rakazo (those HTTP remotes store an api-key-env name only — never a pasted token). Local Herdr talks to Herdr on this host (no SSH; localhost URL only if you choose that). Remote Herdr is SSH-shaped: host + user, optional identity env-var name (path, never a private key) and SSH agent. Health / list / send / interrogate go over SSH to that Herdr host, then to Herdr’s CLIs. Missing SSH config is a clear error — we will not guess a host. kind=herdr

Not configured — add local Herdr or SSH host + user.
